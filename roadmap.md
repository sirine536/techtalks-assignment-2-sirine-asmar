# Six-Month Learning Roadmap

## Goal

Become job-ready for Junior Full-Stack Developer roles by building strong frontend, backend, database, testing, deployment, and software engineering fundamentals.

## Month 1 — Frontend Foundations

- Strengthen HTML and CSS
- Modern JavaScript
- TypeScript fundamentals
- Responsive and accessible UI
- Git and GitHub
- Build small frontend projects

## Month 2 — React and Next.js

- React fundamentals
- Components and state
- Forms and validation
- API consumption
- Next.js App Router
- Server and Client Components
- Build a complete frontend application

## Month 3 — Backend Development

- Node.js
- REST APIs
- Authentication and authorization
- Backend architecture
- Error handling
- API validation
- Build a backend service

## Month 4 — Databases and Full-Stack Integration

- SQL fundamentals
- PostgreSQL
- Database design
- Relationships
- CRUD operations
- MongoDB fundamentals
- Connect frontend, backend, and database
- Build a complete full-stack application

## Month 5 — Testing, Docker and CI/CD

- Unit testing
- Integration testing
- End-to-end testing
- Docker fundamentals
- CI/CD basics
- GitHub Actions
- Environment variables
- Deployment

## Month 6 — Production Readiness and Portfolio

- Performance optimization
- Security fundamentals
- Logging and monitoring
- API documentation
- Improve existing projects
- Deploy portfolio projects
- Prepare CV and GitHub
- Apply to junior opportunities
